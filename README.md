Casafari provides the pioneering, cleanest, and largest real‑estate database in Europe, powered by AI. It enables and accelerates property deals by offering comprehensive property data, analytics, and AI‑driven insights across the continent. The platform includes an MCP for AI agents to query property information, valuations, trends, and recent sales, supporting developers with robust APIs and documentation.

**Areas:** Real Estate Data · Property Sourcing · Valuation · Market Analytics · CRM · Real Estate Software

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Casafari API and MCP Platform: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
